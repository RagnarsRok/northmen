# Development roadmap

## Milestone 1 — Foundation (current)
- [ ] Create GitHub repository and push starter.
- [ ] Confirm clean install, dev server, tests and production build.
- [ ] Agree on domain model and boundaries.
- [ ] Add tested player/game-state types and setup function.

Exit: a clean clone runs, tests and builds; domain code is independent of React.

## Milestone 2 — Map and geography
- [ ] Choose geographic base map/projection.
- [ ] Define territory polygons and stable IDs.
- [ ] Define explicit land adjacency.
- [ ] Define sea nodes and route edges.
- [ ] Validate coastal ports and map connections.
- [ ] Render selectable territories from data.

## Milestone 3 — Setup and economy
- [ ] Finalise 3–5 player setup and starts.
- [ ] Define starting assets and resource production.
- [ ] Implement resource accounting and settlement construction.
- [ ] Add balance tests/simulations.

## Milestone 4 — Maritime systems
Ports/upgrades, ships, embarkation, sailing, trade, naval conflict.

## Milestone 5 — Land systems
Recruitment, movement, raids, combat, conquest, Settlement Event Deck.

## Milestone 6 — Complete game loop
Turn phases, actions, victory conditions, save/load, hot-seat play.

## Milestone 7 — Polish and release
UI/UX, map art, cards, accessibility, onboarding, playtesting and balancing.

Visual foundations should be established early and refined continuously.
